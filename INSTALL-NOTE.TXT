Installation Notes
==================
Installation instructions for Transparent Data Encryption for PostgreSQL Free Edition

Requirements
============
1. PostgreSQL server
2. pgcrypto
3. PostgreSQL development headers and libraries
   # These are not required if you installed tdeforpg from RPM.

Installation and Configuration
==============================
1. Install pgTDE from RPM
    $ sudo dnf install <rpm_file>.rpm

2. Install pgTDE from source code
    # If you installed tdeforpg from RPM, please skip this section.
    $ make PG_CONFIG=/usr/pgsql-<pgver>/bin/pg_config
    $ sudo make PG_CONFIG=/usr/pgsql-<pgver>/bin/pg_config install
    # <pgver> is the major version of PostgreSQL (e.g. 18)

3. Configure PostgreSQL and install pgTDE extension
    $ vim $PGDATA/postgresql.conf  # add data_encryption to shared_preload_libraries
    shared_preload_libraries = 'data_encryption'
    $ pg_ctl restart
    $ psql -d <db_name> -c "CREATE EXTENSION tdeforpg CASCADE"
    NOTICE:  installing required extension "pgcrypto"
    CREATE EXTENSION

Usage
=====
An encryption session must be started before encrypting or decrypting data.
Otherwise, an error will occur.

1. Register an encryption key
    $ psql -d <db_name>
    =# SELECT cipher_key_disable_log();
    =# SELECT cipher_key_regist(NULL, '<encryption_key>', 'aes');

2. Start an encryption session
    =# SELECT pgtde_begin_session('<encryption_key>');
    =# SELECT cipher_key_enable_log();

3. Encrypt and decrypt data
    =# CREATE TABLE test_tde (id integer, data encrypt_text);
    =# INSERT INTO test_tde VALUES (1, 'Hello, world!');
    =# SELECT * FROM test_tde;
     id |     data
    ----+---------------
      1 | Hello, world!
    (1 row)

4. End the encryption session
    =# SELECT pgtde_end_session();
